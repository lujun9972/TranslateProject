These Are The Most Useful FOSS Android Apps I Discovered in 2024
======
It would be a shame if you had an Android smartphone without some of
these interesting open source apps in 2024. Try them out!
[![][1]][2]

Just as I discovered some really cool apps for Linux, the case has been the same for [FOSS Android][3] apps. There were many that took me by surprise, and some that disappointed me as I used them more.

As 2024 comes to a close, it's a great time to look back on some wonderful open source Android apps that stood out this year. From security-focused apps to general-purpose apps such as keyboards and downloaders, we had plenty that piqued our attention.

Let's kick things off! 😎

**Suggested Read** 📖

![][4]

### 1\. Exodus

![][5]

**⭐ Key Highlights:**

  * Regularly Updated
  * Data Collection Insights
  * App Permissions Analysis



We begin with [Exodus][6], an Android app that **helps track which apps are employing what kind of trackers** , allowing users to deep dive into each app's tracker details. It shows helpful insights on potential privacy risks, enabling anyone to make an informed decision about the apps they install.

All of that is made possible due to the [εxodus][7] privacy auditing platform that lies underneath, checking for app behavior like ads, tracking, and analytics that could affect a user's privacy.

[Exodus][6]

### 2\. Simple Keyboard

![][8]

**⭐ Key Highlights:**

  * Minimal Interface
  * Highly Customizable
  * No User Data Collection



This is a personal favorite of mine. [Simple Keyboard][9] is **a minimal open source keyboard app** that doesn't collect user data or implement trackers. It offers plenty of useful features like auto-capitalization, customizable themes, changeable keyboard height, and more.

It is designed to be a no-nonsense, lightweight keyboard app that doesn't get in the way. You can learn more here:

![][4]

[Simple Keyboard][10]

### 3\. Currencies

![][11]

**⭐ Key Highlights:**

  * No Ads/Tracking
  * Easy-to-Use Interface
  * Multiple Data Providers



If you are traveling abroad or are just curious what your next purchase would cost if you were to import it from some foreign marketplace, an app like [Currencies][12] is what you are looking for.

Thanks to its **** regularly updated data sources, you can **search for currency exchange rates on the go** by using its clean, user-friendly interface. You can even add your favorite currencies so that you don't have to search for those each time you open the app.

[Currencies][13]

### 4\. Password Monitor

![][14]

**⭐ Key Highlights:**

  * Minimal User Interface
  * Gives Helpful Suggestions
  * Supports Incognito Keyboard



In an age of constant cybersecurity threats, having secure passwords is a crucial thing. Sure, you can use [password managers on desktop][15], but keeping track of any compromised passwords is just as important.

[Password Monitor][16] can help you do that. From the developer of [IYPS][17], it is an open source password checker tool that has tight integration with [Have I Been Pwned?][18], allowing the app to search through a global database of compromised passwords.

[Password Monitor][16]

### 5\. Ente Auth

![][19]

**⭐ Key Highlights:**

  * Runs Offline
  * Cross-Platform
  * Optional Cloud Backup



From the house of [Ente][20], the [Ente Auth][21] app is a free, open source authentication tool for Android (and other platforms) that has been designed as **a privacy-focused alternative to the likes of Authy**. It features end-to-end encryption, can show a user the next authentication code for ease of use, and can be integrated with a smartphone's screen lock ( _biometric/conventional_ ).

**Suggested Read** 📖

![][4]

[Ente Auth][22]

### 6\. Seal

![][23]

**⭐ Key Highlights:**

  * Fast Downloads
  * Supports Many Platforms
  * Reliable Download Management



Ever felt the need to download that spicy Arch Linux meme on YouTube, but couldn't because you would have to sign up for a paid subscription? Well, then you can use [Seal][24], a Kotlin-based app that is powered by [yt-dlp][25].

It features **customizable options for video quality, audio formats, and subtitle downloads**. Just keep in mind that it can only handle one video at a time.

Seal also supports other platforms that yt-dlp does, so you can download content from Facebook, Instagram, TikTok, and [many others][26].

[Seal (F-Droid)][27]

### 7\. Hacki

![][28]

**⭐ Key Highlights:**

  * Has Offline Mode
  * Highly Customizable
  * Many Engagement Tools



If you are a regular on [Hacker News][29], then you should definitely check out [Hacki][30]. It is **a feature-rich, open source client that supports logging into a Hacker News account** , allowing access to many features like voting, commenting, saving, etc.

It is cool to see someone develop such a client, as the Hacker News platform is a popular choice among tech professionals, developers, and startup founders. Having a mobile app ( _even an unofficial one_ ) just makes it easier for people to interact with each other.

[Hacki][30]

### 8\. NetGuard

![][31]

**⭐ Key Highlights:**

  * No Root Required
  * Intuitive Interface
  * Allows Granular Control



We culminate this roundup with [NetGuard][32], **an open source Android firewall app that can block internet access for specific apps** without requiring root access. It offers functions like network access toggles, traffic logs, and advanced rules, enabling high levels of privacy and data usage control.

You can learn more about it here:

![][4]

[NetGuard][33]

### Wrapping Up

2024 has been a fantastic year for discovering and using FOSS Android apps. The ones listed above prove **how the open source community can band together to provide high-quality applications** that care about the user, not their data.

As we move into 2025, I thoroughly look forward to discovering new offerings. If anyone happens to have any suggestions or resources, feel free to send them in the comments below or via [email][34].
