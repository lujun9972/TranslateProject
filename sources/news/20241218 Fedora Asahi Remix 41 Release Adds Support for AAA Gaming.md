Fedora Asahi Remix 41 Release Adds Support for AAA Gaming
======
Fedora Asahi Remix 41 makes your Apple hardware more useful with Linux
onboard.
[![][1]][2]

Born out of close collaboration of the [Fedora][3] and [Asahi Linux][4] projects, Fedora Asahi Remix is **a remarkable Linux distribution for Apple Silicon Macs** that has gone on to surprise many people.

It offers a minimal installation experience that’s approachable even for non-technical users, leading to a fully-fledged Linux desktop powered by Fedora, making it a great choice for a wide variety of use cases.

Yesterday, in an [announcement][5], the developers dropped a new release with some cool features for both regular users and gamers.

## 🆕 Fedora Asahi Remix 41: What's New?

![Source: Fedora Magazine][6]

Based on [Fedora 41][7], Fedora Asahi Remix 41 has arrived with many improvements across the board, like [Linux kernel 6.11][8], [DNF 5][9] as the CLI package manager, and various tweaks for supporting [MIPI cameras][10].

For the desktop environments of this release, there is [KDE Plasma 6.2][11] for the flagship desktop experience, where there are new additions like tweaked accent colors, an improved System Tray, a reworked Widget Explorer, improved power management, and better color management.

Plus, there is **a new custom Calamares-based initial setup wizard** for this variant.

![A screenshot of KDE Plasma 6.2 for reference. \(Source: KDE\)][12]

Similarly, for the GNOME variant, Fedora Asahi Remix 41 ships with [GNOME 47][13], which introduces many changes like support for accent colors, an improved Nautilus file manager, modernized dialog windows, and many significant updates for the user interface.

![A screenshot of GNOME 47 for reference.][14]

**As for the gamer-centric changes** , Fedora Asahi Remix can now run [AAA games on Apple Silicon][15] thanks to the implementation of a new conformant [Vulkan 1.4][16] driver, allowing demanding titles such as [Control][17] to run smoothly on Apple hardware.

Additionally, there is [x86/x86-64 emulation][18] that allows users to run even more PC-centric applications, expanding compatibility to a great degree.

As usual, this release is offered in **two additional variants** : A minimal image that provides a lightweight, bare-bones system for customizing one's experience, and a server image designed for headless operations and server-focused workloads.

## 📥 Get Fedora Asahi Remix 41

If you have an Apple Silicon Mac device ( _M1/M2_ ) that's running macOS 13.5 or 14.2, then you can run the following command to get a fresh installation of the new release:

```

    curl https://fedora-asahi-remix.org/install | sh

```

Thereafter, follow the on-screen prompts to get Fedora Asahi Remix 41 installed. If you want the nightly builds, then you can refer to the [installation guide][19].

**For existing users** running Fedora Asahi Remix 39 or 40, they can follow the [Fedora upgrade process][20] to get the new release.

You can also visit the [official website][21] if you would like to learn more about the project.
