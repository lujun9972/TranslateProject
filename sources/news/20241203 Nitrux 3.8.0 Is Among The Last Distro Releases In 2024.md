Nitrux 3.8.0 Is Among The Last Distro Releases In 2024
======
Nitrux 3.8.0 is a nice upgrade!
[![][1]][2]

Nitrux is a [beautiful Linux distro][3] that combines the power of Debian, KDE Plasma, [AppImage][4], and [immutability][5] to offer a performant package that is unlike any other.

Designed to be a sleek and user-friendly experience, **Nitrux's developers are quite active in pushing out new upgrades to it**. They are ending 2024 with a big release that has many exciting things to offer.

Let's dive into it! 😃

## 🆕 Nitrux 3.8.0: What's New?

![][6]

Code-named “ _db_ ” to reflect the **focus on improved performance and hardware integration** , Nitrux 3.8.0 is powered by Linux 6.12.1-1 (Liquorix), with numerous improvements to offer.

We kick things off with the changes to Nitrux's [Calamares][7] configuration, where a non-functional kernel parameter was removed, and some new ones added to prevent [clock drift][8] in some laptops.

The [OpenRC][9] init implementation also sees changes, with various services now being sorted into [runlevels][10] and the removal of some services from _async_ , _default_ , and _sysinit_ to **improve boot time**.

The developers have also worked on adding an OpenRC service script that enables [Dynamic Boost][11] on supported NVIDIA GPUs, and another service to change the ownership of an Intel-related file to allow [MangoHud][12] to display power consumption of Intel CPUs.

Various applications and packages have been updated too, with Nitrux 3.8.0 featuring [Firefox 133][13], [Nitrux Update Tool System 2.1.9][14], and [Mesa 24.2.8][15].

Other notable changes include **updated offline documentation** , **the addition of an NVIDIA binary** for enabling the creation of NVIDIA device nodes, and a new [zenergy][16] kernel module for allowing MangoHud **to display the power consumption of AMD Zen processors**.

More details on this Nitrux release can be found on the [announcement blog][17] and [release notes][18].

## 📥 Download Nitrux 3.8.0

This release can be downloaded from the [official website][19], [FOSS Torrents][20], and [SourceForge][21].

[Nitrux 3.8.0 (FOSS Torrents)][20]

**For existing users** , they can run a system upgrade using Nitrux Update Tool System ( _nuts_ ) by running the following command:

```

    sudo nuts update

```

Moreover, the official [upgrade guide][22] is an excellent resource if anyone needs further pointers during the upgrade.
