It's the release week. [Fedora 42][3] is already out. [Ubuntu 25.04][4] will be releasing later today along with its flavors like Kubuntu, Xubuntu, Lubuntu etc.

In the midst of these two heavyweights, [MX Linux][5] and Manjaro also quickly released newer versions. For Manjaro, it is more of an ISO refresh, as it is [a rolling release distribution][6].

## 💡 Quick Handy Tip

You can make [Thunar][31] open a new tab instead of a new window. This is good in situations when opening a folder from other apps, like a web browser. This reduces screen clutter.

![][32]

First, click on _Edit_ ⇾ _Preference_ s. Here, go to the _Behavior_ tab. Now, under " _Tabs and Windows_ ", enable the first checkbox as shown above or all three if you need the functionality of the other two.
