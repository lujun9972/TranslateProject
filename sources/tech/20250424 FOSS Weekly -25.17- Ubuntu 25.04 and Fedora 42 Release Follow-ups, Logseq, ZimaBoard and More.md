## ❇️ Valkey – The Drop-in Alternative to Redis OSS

With the change of Redis licensing in March of 2024 came the end of Redis as an open source project. Enter Valkey – the community driven fork that preserves and improves the familiar high-performance, key-value datastore for improving application performance.

Stewarded by the Linux foundation, Valkey serves as an open source drop-in alternative to Redis OSS – no code changes needed, with the same developer-friendly experience. For your open source database, [check out Valkey][5].

## 🗓️ Tech Trivia

On April 20, 1998, during a demonstration of a beta version of Windows 98 by Microsoft's Bill Gates, at COMDEX, the [system crashed in the live event][35].
