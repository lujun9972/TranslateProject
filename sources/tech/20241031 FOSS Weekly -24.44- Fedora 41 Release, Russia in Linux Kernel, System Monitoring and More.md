## 📰 Linux News

  * Raspberry Pi OS has moved to being [Wayland by default][10].
  * [Vivaldi 7.0][11] was recently introduced with a futuristic redesign.
  * Digital Ocean has made available [one-click AI model deployments][12].
  * Syncthing's Android app [will not receive][13] any new updates after 2024.
  * Google has open sourced their [watermarking tech][14] for AI-generated text.
  * Edera has [introduced OpenPax][15], an open source kernel patch that focuses on security.
  * [32-bit builds for Kali Linux are no more][16], the developers have shared the rationale behind this move.
  * The OSI has finally unveiled [the definition][17] for open source AI. But it leaves out something important.



And Fedora 41 is here, a few days ahead of the schedule which is something new for Fedora releases 😀

## 🧮 Linux Tips, Tutorials and More

  * Run GPU-heavy tasks? [Check GPU usage][20] by using the command line.
  * Checking the temperature of NVMe SSD is easy, just follow [our guide][21].
  * And if you have Rockchip device, you can [check its NPU usage][22], too.
  * Similarly, you can do the same for [checking the CPU temperature][23] on Ubuntu.
  * Need something more elaborate? Then you could [give CPU-X a try][24], it is a CPU-Z alternative for Linux.
