FOSS Weekly #25.22: Microsoft's Vim Alternative, Kernel 6.15, UBXI Desktop, End of Ubuntu 20.04 and More
======

[![Warp Terminal][1]][2]

Important thing first. [Ubuntu 20.04 LTS version will be reaching its end of life][3] on 31st May. It was released in April 2020 and had a standard support of five years.

Please [check your Ubuntu version][4] and if you are using 20.04, you can:

  * Do a fresh installation of [Ubuntu 24.04 LTS][5] to get the latest packages.
  * Upgrade to Ubuntu 22.04 LTS from your existing 20.04 installation, keeping your files intact.
  * Opt for [Ubuntu Pro][6], which will ensure you get essential security patches until 2030 but no new software.



![][7]

Time to plan your update.

## 💡 Quick Handy Tip

In Xfce, you can use the panel item " _Directory Menu_ " to get quick access to files from anywhere. This is like the [Places][35] extension in GNOME, but better.

![][36]

In the configuration menu for it, provide the file extension in the following format `*.txt;*.jsonc` as shown in the screenshot above to access the files quickly. Clicking on those files opens it in the default app.
