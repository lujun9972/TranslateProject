## 💡 Quick Handy Tip

If you are using [Vivaldi][30], you can rename tabs by simply _double-clicking_ on the tab title and entering a name. Before doing that, ensure that double-click tab rename is enabled in the settings.

Open _Settings_ and go to the _Tabs_ section. Here, check whether the double-click action is set to " _Rename tab_ ".

![][31]

This is useful when the tab names are taking up too much space, this way, you can give a nickname to easily identify the tab.
