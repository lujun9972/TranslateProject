FOSS Weekly #26.43: Kernel 7.3, Non-Linux OS, de-Googled Phone, DuxOS, Podcasts, De-bloating TVs, KDE Dock and More
======

[![Warp Terminal][1]][2]

Steam’s Linux client [is going 64-bit and containerized][3]. Running the client inside Steam Runtime containers, like its games already do, should make it behave more consistently across different distros.

[Ubuntu 26.10][4] is out now. This interim release completes the rustification of core utilities, adds Sequoia PGP to the main archive, and brings [Linux 7.3][5] with Snapdragon X2 Elite support and better GPU memory handling.

Fedora 45 release is delayed, and it should now be released on 30th October.

CutefishOS is making a comeback with [a completely rebuilt desktop][6] written using Anthropic’s Fable and Opus AI models. Ships with its own Wayland compositor and graphics library, skips Qt and GTK entirely, and launches apps quickly.

Dux Labs is [the new name for Dank Linux][7] and its Wayland suite, now that DMS has grown beyond a single product. The rebrand coincides with DMS 2.0, which adds Material 3 design, a new file manager, and widget support.

## 🧠 What We’re Thinking About

A €115 billion price tag for Europe’s cloud independence sounds steep [until you note who paid for the study][8]. Amazon, Google, and Meta funded the report through their lobby group, warning against rules that would dilute their market power.
