## 💡 Quick Handy Tip

The Ubuntu system settings offer only **limited settings to tweak the appearance of desktop icons**. In fact, the desktop icons that come pre-installed in Ubuntu are achieved through an extension.

So, if you have [GNOME Shell Extensions][35] installed in Ubuntu, then you can access a lot more tweaking options for the desktop icons.

![][36]

After installing it, open it and click on the cogwheel button near the " _Desktop Icons NG (DING)_ " system extension. As you can see in the screenshot above, other Ubuntu features like Window Tiling, AppIndicators, etc. can also be tweaked from here.
