FOSS Weekly #25.10: Skype is Dead, GNOME 48 Features, Ubuntu Versions, Nano Guide and More Linux Stuff
======

[![Warp Terminal][1]][2]

[Skype is being discontinued][3] by Microsoft on 5th May.

Once a hallmark of the old internet, Skype was already dying a slow death. It just could not keep up with the competition from WhatsApp, Zoom etc despite Microsoft's backing.

While there are [open source alternatives to Skype][4], I doubt if friends and family would use them.

I am not going to miss it, as I haven't used Skype in years. Let's keep it in the museum of Internet history.

Speaking of the old internet, [Digg][5] is making a comeback. 20 years back, it was the 'front page of the internet'.

## 💡 Quick Handy Tip

You can play Lofi music in VLC Media Player. First, switch to the Playlist view in VLC by going into _View_ → _Playlist_.

Now, in the sidebar, scroll down and select _Icecast Radio Directory_. Here, search for _Lofi_ in the search bar.

![][36]

Now, double-click on any Lo-fi channel to start playing. On the other hand, if you want to listen to music via the web browser, you can use [freeCodeCamp.org Code Radio][37].

## 🗓️ Tech Trivia

In 1953, MIT's [Whirlwind][39] computer showcased an early form of system management software called "Director," developed by [Douglas Ross][40]. Demonstrated at a digital fire control symposium, Director automated resource allocation ( _like memory, storage, and printing_ ), making it one of the earliest examples of an operating system-like program.
