FOSS Weekly #25.13: Kernel 6.14, Zorin 17.3, EU OS, apt Guide and More Linux Stuff
======

[![Warp Terminal][1]][2]

Rust in Linux kernel is not news. You already know about that. But Rust in GNU is a big move.

It seems that a Rust rewrite of GNU's coreutils (meta package that gives us commands like cp, ls, dd, mv etc) [will be included in Ubuntu][3]'s upcoming release.

This concerns many hardcore Free Software supporters, as they see it a move to take GNU out of GNU Linux.

## 📰 Linux and Open Source News

  * [Flowblade 2.20][7] has been released with many changes.
  * [Forge1][8] is ArmSoM's latest offering for embedded use.
  * Chimera Linux no longer supports the [RISC-V CPU architecture][9].
  * Ubuntu has added [official support][10] for NVIDIA Jetson AI modules.
  * Fauna database has shut down, but there are [talks of open sourcing it][11].
  * [Zorin OS 17.3 release][12] replaces Firefox with Brave.
  * [Freedesktop SDK removes OpenH264][13] due to maintenance issues.

## 💡 Quick Handy Tip

In GNOME, you can use the [_Auto Move Windows_][30] extension to automatically open new app windows in specific workspaces. First, install it either from the webpage, or via [Extension Manager][31].

![][32]

In the extension settings page, select the windows and the corresponding workspace to automatically move new windows into workspaces. Now, new windows should appear in their designated workspaces.

## 🗓️ Tech Trivia

On March 24, 1896, Russian physicist [Aleksandr Popov][35] successfully transmitted radio signals over 250 meters between buildings at St. Petersburg University. This achievement followed his 1895 presentation of a wireless lightning detector.
