DankMaterialShell Becomes Dux Shell as Dank Linux Rebrands to Dux Labs
======

[![Warp Terminal][1]][2]

[Dank Linux][3], the Wayland desktop suite built around DankMaterialShell (DMS), has put out its [final post][4] on X under that name, bidding farewell to its old identity. Accompanying it is [DMS 2.0][5], codenamed " _Heisenberg,_ " which reached GitHub just a few hours ago.

If you didn't already know, the shell is a Quickshell and Go project that stands in for tools like _waybar_ , _swaylock_ , _mako_ , and _fuzzel_. Around it sit a greeter, a calendar app, a system monitor, and a search service.

It began as a hobby project, with 1.0 shipping in December last year. Since then, newer releases have added niceties like desktop widgets, a new launcher, and spring-based motion.

With that many components in the suite, the project has now put all of them [under a new name][6].

### A surprise rebrand

![][7]

The rebranding covers the whole suite. DMS is now [Dux Shell][8], and the greeter, search tool, system monitor, and calendar are now _Dux Greeter_ , _Dux Search_ , _Dux GOP_ , and _Dux Calendar_ , respectively.

Dank Linux gets renamed [Dux Labs][9], which also acts as the new name for the project as a whole and for every app in the suite.

[**Dux Files**][10] is a standalone file manager that is the one piece that's new instead of being renamed. It offers features like tabs, split views, trash, and network shares. It picks up your DMS theme if the shell is running.

Dux is the suite's mascot, and the name echoes Linux's penguin mascot, Tux. Starting with a D also lets the `dms`, `dcal`, and `dgop` commands keep their names.

**The project's reasoning** to go through the rebrand is that a name built around one product no longer fits a suite with its separate collection of apps and a plugin community.

Another thing to note is that the earlier release, [DMS 1.6][11], still carried the Dank name, and its roadmap listed a standalone file browser and phone integration, but a rename was never really mentioned.

**As for the DMS 2.0 release** , it is a packed one that adds a _**Material 3 Expressive**_ redesign, plugins for the dashboard and dock, and a lock screen with widgets you can arrange yourself.

It also adds **Dux Dot** , a free-floating companion or replacement for the bar that can turn into notifications, weather, media, and wallpaper views, as well as the control center, dashboard, and launcher.

### What now?

The project has already moved from the _AvengeMedia_ umbrella to a new GitHub organization called [Dux Labs][12].

You will find many repositories that used to be known by their Dank names, including dux-shell (previously DankMaterialShell), dux-gop (dgop), dux-search (danksearch), dux-calendar (dankcalendar), and dux-greeter (dank-greeter).

Personally, I preferred the Dank branding. But if the developers feel this is the best approach and the community accepts it, there's no point talking about what was.
