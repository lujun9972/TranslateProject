## 💡 Quick Handy Tip

If you are using [GNOME Boxes][33], you can send keyboard shortcuts like `CTRL+ALT+F6`, `CTRL+ALT+DEL`, etc. without affecting the host system.

![][34]

Click on the " _Keyboard_ " button on the top-right of the GNOME Boxes Guest window. Here, select the required signal from the drop-down menu. This is useful in cases where you want to access TTY as a guest.

## 🗓️ Tech Trivia
