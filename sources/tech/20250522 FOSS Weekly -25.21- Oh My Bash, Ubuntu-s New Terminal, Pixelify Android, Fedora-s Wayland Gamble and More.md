## 💡 Quick Handy Tip

In file managers like Nemo, Nautilus, etc., you can easily create file duplicates by pressing the _CTRL_ key and dragging the file to a blank space in the window.

If you drop a file while pressing the _CTRL_ key when in another folder, the file will be copied to that directory.

![][36]

Use _CTRL+Z_ to undo the file duplication. During this, your file manager will ask you whether you want to delete the copied file.
