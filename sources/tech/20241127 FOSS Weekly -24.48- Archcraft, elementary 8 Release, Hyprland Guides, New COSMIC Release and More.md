## 💡 Quick Handy Tip

On Linux Mint, you can choose a new default terminal application. For doing this, search and open " _Preferred Applications_ ", then scroll down to the bottom and select a terminal app from the list.

![][34]

You can also provide custom arguments in the field that appears below the selector. Just remember, the default one on your LM installation is good enough, switch only if you feel the need for it.

![][35]

If you are looking for a new one, then our [Top 14 Terminal Emulators][36] list should be helpful.

## 🗓️ Tech Trivia
