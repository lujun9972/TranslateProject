Fedora Asahi Remix 45 is now available
======

![][1]

We are happy to announce the general availability of Fedora Asahi Remix 45. This release brings [Fedora Linux 45][2] to Apple Silicon Macs.

### What’s included

[Fedora Asahi Remix][3] is developed in close collaboration with the [Fedora Asahi SIG][4] and the [Asahi Linux][5] project. This release incorporates all of the exciting improvements brought by [Fedora Linux 45][6]. Like previous releases, Fedora Asahi Remix 45 supports Apple M1 and M2 systems. In addition, this release includes out of the box initial support for Apple M3, M3 Pro and M3 Max. Asahi Linux upstream now [officially supports][7] these new systems. The GPU drivers enabling performant 3D acceleration on the M3 systems are not included at this point. They will be available via a Mesa update in the future.

Fedora Asahi Remix offers [KDE Plasma 6.8][8] as our flagship desktop experience. All of the new and exciting features brought by [Fedora KDE Plasma Desktop 45][9] are included.

A GNOME variant is also available, featuring [GNOME 51][10], with both desktop variants matching what Fedora Linux offers. Fedora Asahi Remix also provides a Fedora Server variant for server workloads and other types of headless deployments. Finally, we offer a Minimal image for users that wish to build their own experience from the ground up.

### Installation

You can install Fedora Asahi Remix today by following our [installation guide][11]. Follow the usual Fedora Linux [upgrade process][12] for existing systems running Fedora Asahi Remix 43 or 44. Upgrades via GNOME’s Software application are unfortunately unavailable. Either KDE’s Plasma Discover or DNF’s [System Upgrade][13] command must be used.

### Contacts

Please report any Remix-specific issues in our [tracker][14], or reach out in our [Discourse forum][15] or our [Matrix room][16] for user support.
